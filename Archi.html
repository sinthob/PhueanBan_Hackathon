❌ Email / Password Auth
login.js · signup.js · AuthProvider
Line OA ไม่มี email login — ทุกคนเข้าผ่าน LINE Account อย่างเดียว, Supabase signInWithPassword ใช้ไม่ได้
ใช้ LINE Login OAuth 2.0 + backend ตรวจ userId → สร้าง session เอง หรือต่อ Supabase ด้วย custom JWT
❌ Friends Social Graph
friends.js · friend-profile.js
Line OA ไม่มี concept "friend list" ในแอป ไม่รู้ว่าใคร follow OA บ้าง ไม่มี QR add friend ระหว่าง user, ไม่มี recommendedFriends API
ต้องสร้าง friends table ใน backend เอง ให้ user เพิ่มเพื่อนผ่าน LIFF แล้ว match ด้วย LINE userId
❌ Interactive UI State
useState ทุกหน้า · expand/collapse · cycleStatus
Flex Message เป็น static — กดปุ่มได้ แต่ render ใหม่ไม่ได้ ไม่มี useState, accordion toggle, animated transitions ทั้งหมดหายไป
ส่ง Flex ใหม่ทุกครั้งที่ state เปลี่ยน (reply/push) หรือเปิด LIFF ที่ reuse React code เดิมได้
❌ AsyncStorage Local Preferences
aiProfileStore.js · loneliness.js (keys)
LINE OA ไม่มี local storage ใน chat context, AsyncStorage ใช้ได้ใน LIFF เท่านั้น แต่ไม่ persistent ข้าม session, Behavior tracking จาก device หายหมด
ย้าย preferences + behavior log ไป Supabase DB, track จาก server events แทน
❌ Tab Bar Navigation
(tabs)/_layout.js · expo-router Stack
React Navigation / Expo Router ทำงานในแอปเท่านั้น ไม่มีใน Line chat context การนำทางระหว่าง screen ทำในลักษณะเดียวกันไม่ได้
Rich Menu 6 ปุ่มแทน Tab Bar, Postback text นำทาง, LIFF pages แยก URL ต่อ "screen"

ข้อดี vs ข้อเสีย — เปรียบเทียบตรงๆ
✅ ข้อดีของ Line OA
👥
User acquisition = 0 ต้นทุน

คนไทยมี LINE อยู่แล้ว 90%+ ไม่ต้องให้ผู้สูงอายุ download แอปใหม่ ลดอุปสรรคการใช้งานลงอย่างมาก

🔔
Push Notification จริง ไม่ต้องขอ permission

ส่ง safety alert ถึงลูกหลานได้ทันที ไม่มี opt-in permission ซับซ้อน ไม่หลุด notification ไม่ต้องเปิดแอป

💬
Chatbot ใน native environment

messages.js ต้องสร้าง chat UI เอง แต่ใน Line OA การแชทเป็น native feature พิมพ์คำสั่งได้เลยโดยไม่ต้องเปิด tab

📊
Rich Menu = Tab Bar ฟรี ไม่ต้อง code

วางปุ่ม 6 ช่องใต้หน้าจอแชท ทดแทน _layout.js tab bar ได้เลย ไม่ต้องเขียน UI เอง

📢
Broadcast / Segment messaging

ส่งข้อมูลสรุปกิจกรรมรายสัปดาห์หาลูกหลานหลายคนพร้อมกัน แยก segment ตาม role ได้

⚡
Backend logic ย้ายได้เกือบทั้งหมด

Supabase, Loneliness Engine, AI scoring ใช้ได้เหมือนเดิม ย้ายแค่ UI layer ไม่ต้องเขียน business logic ใหม่

❌ ข้อเสียของ Line OA
🎨
UX ถูกจำกัดด้วย Flex Message

ทุก UI ที่สวยงามใน ActivityCard, animation, WarmClearTheme ทั้งหมดไม่ได้ใช้ Flex Message มีแค่ text / image / button เท่านั้น

🔄
Social graph ต้องสร้างใหม่ทั้งหมด

friends.js, friend-profile.js ทั้งหมดต้องเขียนใหม่ Line OA ไม่มี friends concept ไม่รู้ว่าใคร follow OA บ้าง

📱
LIFF มี friction สูง

ทุกครั้งที่ต้องการ interactive UI ต้องเปิด LIFF (มีหน้าจอ loading เพิ่ม) ผู้สูงอายุอาจสับสน ไม่ seamless เหมือนแอป native

📡
Behavior tracking แม่นยำน้อยลง

loneliness.js ติด track session duration จาก AppState ไม่ได้ใน Line context, trackAppOpen/trackSessionEnd ต้องเปลี่ยนวิธีเก็บข้อมูลทั้งหมด

🔐
Auth เปลี่ยนทั้งระบบ

AuthProvider ทั้งหมด (signInWithPassword, signUp, RouteGuard) ต้องเขียนใหม่หมด แทนด้วย LINE Login flow ที่ซับซ้อนกว่า

💰
ค่าใช้จ่าย LINE Messaging API

Free tier มีจำกัด (1,000 messages/เดือน), ถ้า push notification บ่อยๆ ค่า message เพิ่มขึ้นตามจำนวน user

🗺️ แนวทางที่แนะนำ — Hybrid Strategy (3 Phase)
PHASE 1 · เริ่มต้น
Line OA เป็น Notification Layer
  • ส่ง Safety Signal push ทุกครั้งที่ level เปลี่ยน
  • ส่ง Flex Card สรุปกิจกรรมรายวัน/สัปดาห์
  • Rich Menu: ดูรายงาน / โทรด่วน / ประวัติ
  • Webhook รับคำสั่งข้อความ "สถานะวันนี้"
  • แอปเดิมยังทำงานควบคู่กันไป
PHASE 2 · ขยาย
LIFF สำหรับ Interactive
  • LIFF: Activity Preferences (reuse 80%)
  • LIFF: Loneliness Score Dashboard + Chart
  • LIFF: สมัครสมาชิก / ตั้งค่า Profile
  • LIFF: Create Activity form
  • Behavior tracking ย้ายไป server-side
PHASE 3 · เต็มรูปแบบ
Full Line OA Experience
  • LIFF Friends system + social graph
  • Chatbot AI ผ่าน Webhook โดยตรง (ไม่ต้องเปิด tab)
  • LINE Login แทน email auth ทั้งหมด
  • Broadcast segment ตาม risk level
  • พิจารณาลด native app ถ้า user adoption ดีพอ
สิ่งที่ควรเก็บไว้ในแอป native
ยังต้องการแอป
  • ActivityCard UI ที่สวยงาม / branded
  • Real-time session tracking (AppState)
  • Push notification แบบ native (APNs/FCM)
  • Offline-first experience
  • Full camera/image picker access
